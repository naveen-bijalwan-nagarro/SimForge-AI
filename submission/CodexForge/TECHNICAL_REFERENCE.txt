README, setup.cmd, start.cmd and the synthetic FactoryPulse input packet.

PowerShell: .\setup.cmd followed by .\start.cmd, as described in README.md. The startup
script serves the built UI and API together at http://127.0.0.1:8000 by
default. Local dependencies and generated UI assets are recreated on setup.

The submitted recording demonstrates the built solution. Synthetic costs,
delays and learning scores are illustrative practice evidence.
